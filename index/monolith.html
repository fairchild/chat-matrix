the monolith

One FastAPI process runs the reference agent, keeps the history, and renders every piece of HTML the browser ever sees. It sits outside the matrix on purpose — no wire between the ends, no backend to pick — to answer a question the axes can't: what does a good chat UI cost with no chat framework at all?

How it works

Every patch is a Jinja render of the partial the full page uses, so a tool card is described once. Reload rebuilds the page from the store through the same templates; the sidebar is server state and is patched at the end of a turn.

What it showed

The framework you skip moves into a stylesheet you own.

Where the history sits decides what's free. Reload resumes the thread and there is a thread list — about fifty lines — because the store is in the process. None of the four React cells does either; theirs is behind a fetch.

The client stayed ignorant. Ids and five ops. The one coupling found (Stop's delegation) was removed, not accommodated.

The browser's form semantics became the transport, and bit once. Suggestion buttons × required × Starlette's last-wins FormData → the composer sits before the suggestions in the DOM and CSS puts them back. The price of having no client state machine.

The copied agent's diff fired on day one and was paid the same day. The reference grew a model picker between the cell's first commit and its next; the copy was re-synced, a fourth file rode along.

It can't be compared on protocol or topology — it has one of each by construction — so it answers what a chat UI costs without a chat framework, not which framework.

How it was built

plan §3 contracts → A skeleton + flush spike → B1 stream engine B2 templates + CSS B3 client → C integrate + probes → D harness E docs → F fresh-context review → fix round → commit

Fable orchestrated and verified; Opus and Sonnet lanes built against fixed contracts (docs/plans/frontends-jinja.md) so they could run in parallel. The two real bugs — Stop dying after Enter in the busy textarea, and two concurrent turns overwriting each other in the store — came from the fresh-context review, not from any builder or the probes; both were fixed and re-verified with the reviewer's own scripts.

Gates: conformance 18/18 on :3005, the copied files identical to the reference, /chat byte-identical to :8001, four probe flows green — and resume red, by design, because this is the one cell that rehydrates.
